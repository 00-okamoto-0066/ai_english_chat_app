# 🤖 AI English Conversation Chat App

Streamlit、Claude、OpenAI APIを組み合わせて構築した、
パーソナル英語学習・チャットアプリケーションです。

## 🌟 主な機能
- **AI対話機能:** Claudeによるスムーズで自然な英会話チャット
- **音声入力:** OpenAI Whisperを活用した高精度な音声入力
- **音声出力 (TTS):** リスニング学習をサポートするテキスト読み上げ機能
- **学習カスタマイズ:** 目的に応じたレッスンの設定切り替え
- **履歴管理:** 会話履歴のテキストファイル（.txt）保存と履歴の削除機能

## 🛠️ 使用技術
- **UI:** Streamlit
- **Language:** Python
- **APIs:** Anthropic API (Claude), OpenAI API (Whisper / TTS)
